# Playerok Monitor 2.0.0 · One UI 8.5

- One UI light and dark palettes, reachable layouts, Samsung-style motion and haptics.
- Resizable Samsung DeX/foldable layout with mouse and keyboard shortcuts (`Ctrl+R`, `Ctrl+1`, `Ctrl+2`, `Ctrl+,`).
- One UI Quick panel tile, home/Flex Window widget and dynamic app shortcuts.
- Problem author, resolution author and refund author are visible in both the order list and order details.
- Notifications open the exact deal and separate urgent problems/refunds from ordinary orders.
- Requires the matching Playerok Monitor server update deployed to the paired VPS.

The attached APK is CI-built, Android 16 smoke-tested and signed with the GitHub Actions debug key for direct personal installation.
