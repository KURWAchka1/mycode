# Playerok Monitor Desktop 1.0.0

- Полноценный клиент для Windows 11 в стилистике Samsung One UI.
- Новые заказы, продажи, покупки, подробные статусы проблем, возвратов, выполнения и получения.
- Безопасные действия «Я проснулся» и «Выставить снова» с ценой и выбором Premium.
- Общий редактор автосообщений и периода сна с Android-приложением.
- Локальная динамическая статистика без дополнительных запросов к VPS.
- Системные уведомления Windows, область уведомлений и автозапуск.
- Обновление поверх установленной версии через GitHub Releases и Velopack.

Первое подключение выполняется тихо: приложение не показывает старые события как новые уведомления.
