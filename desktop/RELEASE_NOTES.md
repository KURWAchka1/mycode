# Playerok Monitor Desktop 1.1.3

- Placeholder поиска теперь исчезает при фокусе: каретка больше не накладывается на середину текста ни в списке заказов, ни в палитре команд.
- Все всплывающие подсказки получили единый тёмный читаемый шаблон вместо белого системного прямоугольника с невидимым текстом.
- Полноэкранное окно учитывает рабочую область текущего монитора и положение панели задач Windows, поэтому нижняя часть списка и полосы прокрутки не уходят под неё.
- Исправление границ применяется и к дополнительному окну перевыставления товара при разворачивании или Snap Layouts.

Версия устанавливается поверх 1.1.2 и сохраняет Pairing URL, заказы и настройки. Сервер и VPS менять не требуется.
