# Playerok Monitor Desktop 1.1.0

- Полностью новый минималистичный интерфейс, спроектированный как desktop-приложение, а не растянутая мобильная версия.
- Компактная навигационная панель, плотная command bar и рабочая область list/detail без вложенных тяжёлых карточек.
- Адаптивная компоновка для окон от 780 px, включая статистику, поиск, настройки и окно перевыставления.
- Быстрые команды `Ctrl+K`, поиск `Ctrl+F`, обновление `F5`, переходы `Ctrl+1`, `Ctrl+2` и `Ctrl+,`.
- Настройки переработаны в читаемые строки «описание — переключатель»; тексты и функции сервера сохранены.
- Анимация статистики учитывает системную настройку reduced motion и по-прежнему не создаёт запросов к VPS.
- Обновление устанавливается поверх 1.0.0; workflow создаёт delta-пакет на основе предыдущего релиза.

Серверный протокол и Pairing URL не менялись. Первичная синхронизация остаётся тихой и не воспроизводит старые события как новые уведомления.
